基于 Obsdian，个人笔记、文章、记录仓库。

## Structure

```
writing-vault/
 ├─ journal/        ← 游玩/阅读过程性记录、日记
 ├─ thoughts/       ← 作品感想、评价、批评
 ├─ essays/         ← 独立的个人哲思、意识流、散文随笔
 ├─ fiction/        ← 小说创作
 ├─ summaries/      ← 总结
 ├─ tech/           ← 技术文章、学习总结
 ├─ notes/          ← 笔记（读书笔记、课堂笔记）
 ├─ misc/           ← 难以分类的杂项
 └─ lexicon/        ← 词库（Various Complements 用）

```
