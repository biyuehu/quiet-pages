# A4

下午的课程甚是无聊，应试的东西基本都如此。五分钟的午睡更多地是心理安慰作用，该困依旧会困。喋喋不休地在台上讲着经典电磁感应题模型，而又有多少人在有效听讲是一谜题。困是一种必然，但奈何现在不能困倒，不因什么大道理，而是因现在是班主任的课。到底是要点脸不想大众出丑，还是对她权能的畏惧了？应该都有点。被逮了个现行会有种“只有我没认真听课，只有我在对不起自己”的极致负罪感。马上要训满十二年了，结果就是一套无限向内自责、愧疚的负罪感恩机制。
这与宗教又有何异呢？正儿八经的宗教有着千年的历史文化与神学思想背书，而这是新兴的疯狂邪教。
事与愿违，越是想着不要睡着，越是爱胡思乱想让困意更浓。
如同逃不脱的既定命运，我被粉笔成功击中。
「滚后面站着」
若出糗是一位追求者，那他肯定很满足。剧本为他而设定，无论扮演被追求者的我如何严词拒绝，终是逃不过被他雄性荷尔蒙吸引，狠狠拥入其怀抱的命运。
站了大半节课后总算等到了下课铃，就是不知我该以荣归故里还是败走麦城的姿态回到座位。
拜被逮住的命运所赐，后面一节课睡意全无。这节是人见人爱的化学课，不为别的，只为化学老师眼神不好且也不爱管人，反正不会是爱化学。
像是海洋生物首次登岸的伟大尝试，我把手机带到了学校，并在上课中暗自使用这一伟大工业革命产物。接下来我也将变成凶猛健壮的爬行动物。
高一那会儿，有回早上迷迷糊糊地把手机揣了过来，我向上天发誓这真的是不小心。摸到包里的形状时，幼小的心灵即刻吓得躲进厕所，确认无人后检查所有的手机闹铃、提醒，关闭 WIFI、移动数据打开飞行模式，最后关机。如果上课的途中不小心响了可谓跳进黄河也洗不清，要是年级考试时响了，那么全校通报记处分可能免不了。至少嚣张跋扈的校规明文这么写，执行机构是否给力我未实验。手机自发地陷害主人是一回事，主动在堪比神的宫殿的神圣场合偷摸玩手机这类不伦不类的电子产品，而非将灵魂全心全意用在书香笔墨上，这又另当别论，简直是对神圣规则的漠视与僭越，在十字架上火刑万次也赎不清罪责。
比起恨别的，恨自己也是一部分。对服从性测试的规则不主动打破是或许是符合道德的，可为什么自己对被动打破也会感到罪恶感了？我可是在不公规则降临时最反骨的那个啊。说到底最终还是逆来顺受的底色，只是想借反骨证明自己的独特吗？
言而总之，现在这的确是伟大康复计划的第一步尝试。
后排靠窗的经典座位好在离讲课老师远，坏在要时刻提防从永不关闭的后门窜进来的班主任。愿同桌是个好哨兵。虽说在上课那坚不可摧的信任链就遭到重锤。
传言学校免费 WIFI 连不得，一连就出事。且不论学校闲的没事用这方式抓学生干嘛，技术上甄别学生设备、准确上报更不容易，明明一眼假的阴谋论却总有人信。
刷视频是不现实的，蓝牙耳机没带也听不了歌，怎么办呢？习惯性打开几个软件确认后实在是太好了，要是这时有人喷我那我可还得在高危环境下进行实时对线输出。我为了隐蔽光是打个字都够费劲。左滑右滑还是点进了 HitGub 的客户端，同样没有新的 PR 或议题。出于无聊的原因，我转到之前被合并的其中一个 PR 页面里仔细审视起文字。如果被抓不知能否以学习英语为由逃过一劫。非母语阅读果真是良好的催眠剂，不到几分钟困意就回来了。
对手机索然无味后默默放回了包里，抬头的黑板已经从左边写到右边，净是些基础概念简单易懂，变成题目就找不到北的知识。胳膊肘一往桌上杵，脑袋就又开始自顾自搜索记忆材料进行奇思妙想，其中是闪过了昨天那个女生的片段。回望三年，自己跟女生的主动接触和女生跟自己的接触几乎都趋近零，活到这种地步已算不上可悲而是耸人听闻吧。怎么就能这么窝囊了？眼前浮现出诸如：主动回避、不想接触、懒得接触、身高矮小、丑陋自卑、不屑于等选项，不清楚题目是单选题还是多选题。
怎么感觉一整天都在说丧气事了？那就来点开心的吧。刚出炉的新鲜事，在经历上次滑铁卢后这次月考显出了短暂回升的迹象。每次大考的成绩排列起来算是在正负纵轴循环的三角函数图吧，不知道高考时是波谷还是波峰。不，肯定是波峰。
后两节的英语课当然是睡眠自助课了，可惜在最后，困意早已稀释的差不多了。比起困，更焦心如焚的是瞪着墙上挂钟丝毫无法快进到饭点。所以请让我在这里能感受到一种拉动进度条的快进感吧。
我宣布现在到饭点了。
毫不意外，依旧是一个人顾影自怜。食堂还能去嘛？也不是非去不可吧？在临时起意的建设性想法指导下，我决定在学校瞎逛。
