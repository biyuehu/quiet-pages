# A2

下午的课程甚是无聊，准确地说不感兴趣的东西都这样，尤其是应试的。现在是化学课复习工业流程中，一人在台上自说自话的催眠效果堪比普鲁斯特的意识流名作《追忆似水年华》，我记得高一那会儿还是对这门科还是有兴趣的。
拼命撑到傍晚吃饭铃声响起，清醒是清醒了，但突然有点茫然不知道干什么为好。名义吃饭时间里吃饭自然是核心教义，但教义也是需要被外围的各种细节与过程所支撑。无可奈何，饱饭要紧，还是去了慢走要个五分钟的食堂。怎么就论到这地步了？早知道高一那会儿多合群，多找点饭搭子就没这么悲惨了。不是说现在不合群，我在这块还是有尽力的，而是说合群归合群，饭搭子基本都锁死了，弄得跟有限资源一样。得考虑下后续了。
上次跟帆一起吃饭是四天前，怎会去思考自此之后是否就难以见到了？事实上就是之后没在学校见过他了。有点像被甩的落魄单相思男吗？可都是男的啊，哈哈。不过我确实挺“纯情”的，自初中起的交情延续到高中的大部分时候，每天下午总是等对方一起去吃饭，明明一个文科班一个理科班，隔了三层楼。高一那会儿上下学还能顺个路，再后来就不是了，每天就吃饭那二十多分钟能见个面，可却还是能彼此分享，倾诉糟心事也罢，痛骂学校也罢，憎恨命运也罢。抛开尽是些不伟光正的吐苦水或者仇恨言论外，的确是颇有情谊，也曾觉得彼此是相近的孤高者。什么“成长是对与志趣相投的朋友的共同点作减法”的伤感言论应该不会出自我口，可又难以反驳。
昨天晚上收到消息，倒不是帆的，而是一个淡了有一段时间的初中朋友，跟帆为数不多的共同朋友。说是前天晚上闹出大事了，抑郁症，不过所幸没来真的，问我有没有空去看看他。意思是神会了，可骨子里被驯化出来的温良顺从让我难以在一周半休的前景下请假和谢绝对伟大情谊的看望之间做出选择，不过高三时间紧任务重又确实是正当的作案理由。
大概还是没走近他的内心吧，虽说利己角度出发跟我没关系。我几乎总是有什么苦水都跟他倒，有什么糗事都跟他讲，可他却没能把我当作能倾诉的对象吗？实在是突然，听到这一消息。可悲的是自己仔细想想后又觉意料中，毕竟知晓答案后总能从过往片段里编出解释。
就这样，人排着队，手揣着包里，终于到了我。座位依旧找了半天，看来上周与帆的伟大对话里对学校反人类的食堂罪行问题没能有效解决：明明位置就那么点，明明高三累惨了，却还是在错峰机制下恐成最后一批吃饭的。看着旁边刚吃完、嘻嘻哈哈聊着地理课趣事的高一或高二生有点烦，但只能忍着，一方面我没有精神失常与暴力倾向，二方面想早点安稳出狱，三方面都高我卑微的躯体两个头，打不过。
复盘完后，我告诉自己有时间去看看吧。但愿。再然后就是考虑今后的事，真得只能沦落成每日如孤寡老人没伴陪的吃饭时刻吗？最近跟凉及他好兄弟这对连体人倒颇有来往，变成三头六臂应该也不赖。不过跟凉相较，虽说相似可又非相同，加之他跟我也算个争强好胜的固执人，能预见倒新伟大情谊里将偶尔夹杂嘴上炮火味。什么时候去融入他俩吧，我又告诉自己。

一走出食堂门口便听到教学楼传来的欢呼声，我寻思节假日还没到了。不过下一刻就明白了。楼道里有喊着求电别来的，有期盼非人学校停掉今天晚自习的，有已经开始收拾东西的。大概又是县城的电力公司在哪搞出问题了吧。高一冬天那会儿发生过几回。
「等会儿回去干什么？」走廊里呆着的凉问我。
「玩呗」
「不错不错」
「别高兴太早嘛，万一来电了」
「乐观一点啦」
你一句我一句的接着，所幸没问我具体玩什么。
时针走到七点钟，离正常上晚自习时间过去了二十分钟，一个个也在黑灯瞎火下的教室里乖乖地待了二十分钟。只见班主任老东西这时才面露喜色地现了身，走进教室又立马转为严肃。
「你们先别激动——」
刚说完，还没听到下一句便迎来伴随整个教室的轰鸣声，接着左右隔壁班也响了起来，再然后是对面的高二也收到了我们发送的声学信号。老班以不想误触炸弹般的良苦用心成功触发了超声波炸弹。

打开心心念念的手机，显示着七点二十，时间出奇得早，于是又打开了日思夜想的电脑，因为晚上正常时间回到家是没有能碰电脑的奢华时间。也不知道什么时候家里成了一个人，当然不是父母双亡的极致悲剧，只是初三还是高一开始，父母就跑省城打工了，一年就长假时候能回来。到底是出于什么心态，能省心把一正处于关键兼叛逆阶段的大活人丢家里了？倒不是恨他们，事实上，父母在学习这块向来就只对我作很本分的，如“踏踏实实学”的要求，更别提外出后交给我的极大自由时间与每月还算充足的生活费。只是这自由来得太过科幻，换别家即使父母不在也总会有个别的监护人。欠缺着真实，时至今日仍时有这种感想。
打开电脑后的第一步是登录，第二步则是打开 Dhrome 浏览器。顺势看了眼手机，某聊天软件上没什么好友、群聊的新消息，某视频平台上也没有人喷我的逆天言论。得到这一结果便如释重负，只是失望或者放心，只是持续等待确认的缓存清空了。有个邮件消息，是来自 HitGub 的通知，关于新 PR。从软件里跳到了刚打开的浏览器，瞅了下时间，来自几个小时前。所谓 PR，就是某种外人辅助协作他人公开代码开发的流程机制，现在我做的便是称之为 review 的检查流程。这份内容本身没啥，大意是发现代码有几处问题，就提了个议题报告，不知道是觉得无人理会还是怎么打，又自己提了 PR 进行解决。内容是大不了的，“合并”二字的按钮被我一点。偶尔还是会有人给我写的东西提点议题的，但基本不会管就是了——说是不被在乎的自娱自乐玩具项目我于心不忍，可确实算写完了、试探了想法、实现了创意后就不打算管的放养状态。可能我觉得一脸苦闷地面对着暗色的字符文本框，一弄就是大半天的过程本身更有趣。反正，你对我的成果有建设性想法，或者你确实有功于发现了问题，那么你的最佳答案应该是自给自足，而不是要求着脚踏数条船的海王我，去对某个已经被我完成、丧失了新鲜感的旧日女友负责。
总而言之，难得有聪明的外加罕见的主动提 PR 解决的情况。我打开了昵称为 yukio 的主页，那条 PR 的主人。小小 PR 只是一现象，而偷摸着观察现象背后的人是什么来历，则是我总有却不成文的爱好习惯。一览无余的仓库列表，配上毫无装饰的信息页，我不禁怀疑这是不是机器人。不清楚是仓库不多还是说没有公开，能搜刮的仅有一个用 tex 记了一堆我看不懂的数学内容的笔记仓库。就像射出精液后，瞬间索然无味。观察结束。搜刮过了一会儿，我才注意到其实不止一个 PR，还有几个针对我其它仓库的请求。心智负担是不需要的，点点 merge 按钮便好。
