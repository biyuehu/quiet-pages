# A6

又熬到了饭点。传言大学生们会忧虑吃什么的哲学难题，而现在的我则会忧虑到哪里去的哲学难题。
昨晚上的时候，项目被罕见地提了个 issue，针对一个功能建议和发展方向，用着蹩脚的英语逐个翻译成句，偶尔不会的或者忘了的单词则去搜一下加到句子里，最后拼凑出来的句子用翻译器翻回中文看看是否为想的意思，确认完没有问题后我点了回复键。从结果看，直接丢给机器或者 LLM 翻译我的意思更为高效，但自己来一下的话会有“潜移默化中提高英语”的自我安慰。很快我又收到了回复的邮件提醒，来来回回扯了半天，最终向我确认是否可以交给他来做。我说没有问题，并顺带问他要不要 collaborator，我懒得逐一合并。过了会儿收到了“Sure”的确认，我把被合并过的几个仓库都添加了 collaborator。交涉的过程里倒让我学到了点日常的英语缩写，诸如 idk、tks 等。
转折点在于之后有一次回复中，对面直接用中文问我要不直接中文交流算了。先是有点豁然开朗似的惊讶，回道当然可以。后来想想，会不会是受不了我一堆语义混乱的散装英语。
果真没有被锁，我感到庆幸，就像小孩发现全新的秘密基地一样。来这里无非是不一样的风景和安静的发呆地方。明明有着手机却还是不觉得自在，除了在熄屏和亮屏间切换别无它事。切到掌有群主身份的 QQ 小号，群申请总是会有几条，也有被我遗忘了好几天的，因为切到小号看申请通知仅凭我是否能偶然想起。加群问题是从何而来，当然，这是字面意思不包含哲学意味。正确的答案无非是 GitHub 或者 B 站视频，此为群人流量的主要来源。明明有着几百号人平常却鲜有人说话，仅仅在艾特全体成员说即将要开始群内大清洗戒严的时候，才会倾巢哀嚎“别杀我”、“冒泡”。
譬如说现在就有好几条申请，答案都对所以便逐一放行。最早的两天前申请引起了我的兴趣，头像是个笑口常开的老头子，有点眼熟，可怎么也想不起在哪见过。
识图结果指出是个叫阿隆佐的人，顿感无趣。显然，我不会和这位远在大洋彼岸的数学家有任何瓜果。侦探的绝美思绪突然断了线。
不是什么非得纠察到底的窥探欲，好奇心悬在空中总归是难受的。来者的昵称是个很没印象的网名，但卡片资料倒蛮简洁，只是几张不知何意的图片。简洁得少有我能解读的信息。讲到这，也就顺其而然地知道了答案，这不跟那个昵称 yukio 的 GitHub 用户同一头像嘛。
这小号以前是用来挂第三方 BOT，断然就很容易地被各种人拉进五花八门的群聊使用，现由于付不起服务器的费用当然是不了了之了。随手一翻小号加的群，基本也无新消息，全都冷了下来。为什么要让小号当群主呢？比较鲜明的理由是群内出了什么事，用小号会有种并不直接指向自己的错位感，好似躲藏在面具之下的表演者。
人多就会杂，前不久跟群里一奇人观点起了冲突。对方优越而先见地断言道一切学习都应从其口中不知所云、不知所指的、堪比神秘学的“本质”出发，例如学前端接口调用不从TCP原理与计网学起就是只会调库的低劣搬运工。若是初中早已升级为口上暴乱，现在的我只会玩味地有一句没一句挑刺把弄作为反驳。估摸是感悟到我的缜密逻辑无缝可破又手握重权，振振有词地说了句“你承认群聊是你封建领地了？”后被我光速拿下，奖赏三十天禁言。虽然自觉地退群逃逸了，但风趣的发言影响到群聊命运的一生。我深刻领悟奇人的谆谆教诲，自此把群成员活跃等级头衔自定义为草民、足轻、大将、家老、大名，自己则是专属的“风林火山”头衔。
处理完线上事务的我魂归现实，打量起周围的环境。昨天顾着看周遭的风景却忽略了本身的构造让我心生遗憾。不远处是沿着女儿墙一圈安装的避雷带，雷雨天时大概没法来这里了。
不知是否有良好的排水措施，前天下了雨，昨天只有边角处有点水洼，今天则完全烤干了。还算整洁的水泥地面令人心旷神怡，完全不是想象中潮湿肮脏还布满鸟粪、垃圾、青苔的模样。若非如此我自然不会再来。边缘的矮墙上还有栏杆，可也就一米出头的高度，说是防止学生跳楼，不如说是方便我倚靠。就像那个人一样。
会不会是对周围的一切都毫不在乎了？并非持续观察的结论，但大脑给我这种感觉。只是屈膝坐着，安静地看着腿上展开的书本。除了时不时用手翻动一下书页，此外难有其他多余的动作。要说小插曲，可能是某一阵风偷偷吹来，不长不短的头发竟争相往一个方向扬起，如同飘带；不一会儿风停了，飘带垂下来遮挡住眼睛，随之便用手将不听话的几根发丝拨到耳朵旁。
“晚自习”的开场是喘不上气的每日小练习，两科，持续两小时。一周只有周六周日没有，这不因为学校良心发现，而是周六周日晚上会有持续一整晚的六科周考。到了后面，上周周考的卷子都没讲完，这周的小练习又来了，好不容易讲完上周周考，这周周考卷子又要来了。渐渐地，老师们也就演化成了抽几道重点讲解上完课便了事。自高一就有的悠久传统而未断绝，初中那会儿便听这学校高中以题海战术闻名于世，哪知是考不完的试和讲不完的题。就这样了还有自行寻找难题练习的人，我不知是有受虐癖好喜欢玩更极致的窒息 play，还是说产生了戒断反应而无法自拔。
至于质量，周考和小练习都在自己班，监考的，或者说台上坐着的、不怎么管事的吉祥物，也是自己班老师。就周考会意思一下，彼此拉开一下彼此距离，平常基本是你中我有我中有你的答案合成。也有病毒传播的时候，比如某位神奇高手很快做完了小练习，他的真理即刻传遍班里的大部分角落，最后负责任的老师改完后统计错题便会有壮观之景，本有难度的题正确率高得离谱的，几乎全对，或者很简单的题错误率离谱，甚至平日的优等生也栽在了同一个坎上。学生与老师的强烈羁绊使得老师们总对此心照不宣。
熬完小练习后是两节正课，今日是生物与数学。生物课是好的，因为碍于一轮复习进度，几乎有课就会赶而又对台下不闻不问，这令大家能充分利用。今日的额外阅读时间——为什么是额外？因为现在还没到晚五。记不清是怎么了解到这本书的，只是被说很适合现在自己的心境去阅读。总之，昨日及以前读的当是昨日及以前读的，今天的是新书。
「假如我们不是极为独特，假如我们中的每个人，都确实能被一颗炮弹从世上彻底清除，那么讲故事就毫无意义。」
序幕的几句看起来富有道理的话拉住我的目光。准确地说，更像是种电波般的共鸣，觉得在理，觉得道出了心中所想。正式内容读起来确实对得起“电波”一词。诚然我不甚了解什么弗洛伊德、荣格，化写作技巧为实际的这本书，于我而言是艰难咽下的意识流文字。偶尔会遇到令我赞叹为“很有道理”、“确实如此”的哲理名言，如此深刻的哲理值得我拿出笔，在段落处划上线，等待不知哪天翻阅时注意到。前面的剧情是纯情稚嫩的小男主被学校恶霸威胁，不幸走上偷钱道路，在命悬一线之际有过一面缘的同学出现，两三句话赶走了恶霸。
数学课就得安分了，因为数学老师该说是恶毒还是负责了？晚上的课她几乎不讲东西，真得让我们自习，但坏就坏在她可能正在进行某种需要频繁走动的康复训练。今晚小练习发下来，错了两道，一个是我几乎不会碰的极值点偏移题，因为这个名字听来就很邪门，课本也未曾讲过，另一个是令我痛苦难耐的解三角形。说难算不上，可偏偏恶心在就是容易没思路，容易一步错步步错。一说就是练的不够、熟练度没上来。我真纳闷了，到底谁发明这种毫无数学美感的东西。
和几道经典导数题进行暧昧不清的解答尝试后，时间很快来到晚五。昨日起，立了新规，一三五读，二四写，今天是写。
读文字这档事也是进来一两年左右才有的尝试，以前可是想想全是字的书就会浑身发麻。至于吐出文字，那就简直要人老命，半天想不起某个词是常事，多次拜倒在自己无能的表达能力面前。脑袋总是有好几幅精美绝伦的场景，此刻人物的每一细节都清清楚楚，可手却不知道怎么操控笔写成文字。我是不是该去研究下脑机接口呢？
说到底还是模糊的，真要清清楚楚怎会是写不出来？
说到底是模糊的，可就是看不清太远了，某种神秘欲望激发我想知道她现在看的什么书。
手机当然有镜头放大的功能，可被发现会当偷拍变态揣到楼下去吧。如果我反应快点的话应该有存活概率。拜托，你倒是瞅我一眼吧，至少让我知道你知道了我的存在。
高一的上课铃响了，但还没走，居然是高二的吗？明明是跟我差不多的矮个子。不过，我不是女的啊。要知道，这不同于男生，矮个子女生是很有市场的，所谓的身高差萌就是这样来的。真是的，高个的就去找高个啊，你高个还找矮个的，让不让我活呀？
到头来我自己挪了下位置，近了好一段，但又留有算得上不冒犯的距离。
