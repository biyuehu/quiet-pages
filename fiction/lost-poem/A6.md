# A6

又熬到了饭点。传言大学生们会忧虑吃什么的哲学难题，而现在的我则会忧虑到哪里去的哲学难题。
昨晚上的时候，项目被罕见地提了个 issue，针对一个功能建议和发展方向，用着蹩脚的英语逐个翻译成句，偶尔不会的或者忘了的单词则去搜一下加到句子里，最后拼凑出来的句子用翻译器翻回中文看看是否为想的意思，确认完没有问题后我点了回复键。从结果看，直接丢给机器或者 LLM 翻译我的意思更为高效，可自己来一下的话会有“潜移默化中提高英语”的自我安慰。很快我又收到了回复的邮件提醒，来来回回扯了半天，最终向我确认是否可以交给他来做。我说没有问题，并顺带问他要不要 collaborator，我懒得逐一合并。过了会儿收到了“Sure”的确认，我把被合并过的几个仓库都添加了 collaborator。交涉的过程里倒让我学到了点日常的英语缩写，诸如 idk、tks 等。
转折点在于之后有一次回复中，对面直接用中文问我要不直接中文交流算了。先是有点豁然开朗似的惊讶，我答道可以，后来想想，不知是否为受不了我一堆语义混乱的散装英语。
